**Purpose & context**

Zema is building **OMNICORE**, an ambitious multi-agent AI platform hosted on Vercel. The platform is organized around a central orchestrator (**J.A.R.V.I.S.**) coordinating four specialized agents:
- **E.D.I.T.** – social content
- **M.I.N.E.** – Minecraft server management
- **P.R.O.M.P.T.** – coding assistance
- **A.R.T.** – design

The project is a full-stack **TanStack Start** application using **Radix UI**, **Tailwind CSS**, and custom oklch-based design tokens per section. The long-term goal is to make the platform public and announce it on X (Twitter), with ambitions to compete in the autonomous AI agent space.
